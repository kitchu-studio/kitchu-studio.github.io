วิธีทำงานHow I work

ทำคนเดียว คุยกับผมตรง ๆ ไม่ผ่านหลายต่อ One developer, so you talk to the person writing the code.

  1. คุยโจทย์Talk it through

    เล่าว่าร้านทำงานอย่างไร และอยากให้แอปช่วยตรงไหนTell me how the shop runs and where an app would help.

  2. ตกลงขอบเขตAgree the scope

    สรุปหน้าจอและฟีเจอร์ที่จะทำ ก่อนเริ่มเขียนโค้ดWrite down the screens and features before any code.

  3. พัฒนาและส่งให้ลองBuild and try

    ส่งงานเป็นช่วง ๆ ให้ลองใช้จริง และแก้ระหว่างทางShip in small pieces you can use, and adjust as we go.

  4. ส่งมอบHand over

    ส่งโค้ด คู่มือติดตั้ง และขึ้นระบบให้ใช้งานได้Deliver the code, setup notes, and a running system.
